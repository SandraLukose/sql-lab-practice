# 📝 Oracle SQL UPDATE Operations

This folder contains practice questions focused on the **UPDATE** statement in Oracle SQL.

The `UPDATE` statement is a **Data Manipulation Language (DML)** command used to modify existing records in a table. These exercises cover updating single and multiple columns, performing calculations, updating records based on conditions, and working with NULL values.

---

## 📚 Learning Objectives

By completing these exercises, you will learn how to:

- Update a single column in a table.
- Update multiple columns using a single `UPDATE` statement.
- Perform arithmetic operations while updating values.
- Modify records using the `WHERE` clause.
- Update multiple rows based on specific conditions.
- Work with `NULL` values.
- Update calculated fields.
- Use conditional updates in Oracle SQL.
