# SQL Lab Practice

A collection of Oracle SQL lab exercises, solutions, and database design problems designed for students learning SQL and Database Management Systems (DBMS).

---

## 📚 About

This repository contains hands-on SQL practice exercises covering Data Definition Language (DDL), Data Manipulation Language (DML), schema modification, and database design concepts. Each topic includes practice questions and corresponding SQL solutions.

The exercises are organized to help beginners strengthen their SQL skills through structured learning and practical implementation.

## 🎯 Learning Objectives

By completing these exercises, you will be able to:

- Design relational database tables
- Apply SQL constraints effectively
- Write DDL statements
- Perform CRUD operations
- Modify existing database schemas
- Understand relationships between tables
- Solve real-world SQL problems

---

## 🚀 How to Use

1. Open the appropriate topic folder.
2. Read the practice questions in `Questions.md`.
3. Solve the exercises using SQL*Plus.
4. Compare your answers with the solutions in `Solutions.sql`.
